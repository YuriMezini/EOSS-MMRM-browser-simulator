Scripts used with the browser simulator.

Main files:
- eoss_engine.js — simulate trials and fit the JS model
- scenarios.js — Ex1, Ex2, Ex3, and Null settings
- r_mmrm_fit.R — fit the same data in R with mmrm
- run_paired_batch.js — run JS and R on identical simulated datasets
- reexport_r_full_precision.js — export R estimates at full precision
- original_r/ — original simulation helpers for the unpaired R check

The remaining files are validation and batch helpers.
