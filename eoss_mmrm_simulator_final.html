EOSS_MMRM V1.0

Welcome to EOSS_MMRM V1.0

Estimand-Oriented Sample Size and Power Simulation using MMRM — now running entirely in your browser.

The ICH E9(R1) Addendum on Estimands and Sensitivity Analysis in Clinical Trials has been adopted by many regulatory agencies since 2019. Sample size and power calculation, as critical components of trial design, need to be aligned with the chosen estimands and intercurrent-event (ICE) strategies that reflect the trial objectives.

EOSS_MMRM performs sample size and power simulations with an estimand-oriented approach for clinical trials that use MMRM (Mixed-effect Model for Repeated Measures) in their primary endpoint analysis, handling intercurrent events with treatment-policy or hypothetical strategies. It lets you specify expected efficacy at post-ICE follow-up visits together with missing-data patterns and extent, so sponsors and stakeholders can see how different ICE strategies and missing data affect statistical power before a study is run.

The original app vs. what we did

The original EOSS_MMRM V1.0 is an R/Shiny application. To use it you have to install R, install several packages (shiny, DT, MASS, mmrm, dplyr), and launch a Shiny server — a real barrier for teaching, demos, and quick exploration.

What we did: we reimplemented the same simulation workflow as a single, install-free HTML + JavaScript file. Open it in any modern browser — no R, no Shiny, no Python, no server. Heavy computation runs off the main thread in a Web Worker so the page stays responsive, and the trial-generation logic follows the paper directly.

Honest scope: the R app fits the model with mmrm + Kenward–Roger adjustment. The browser version uses an iterative GLS approximation with EM-type covariance updates (not REML). It reproduces qualitative power ordering for the examined compound-symmetry scenarios, but the validated R/mmrm implementation remains the reference for exact statistical inference.

An HTML implementation of EOSS_MMRM V1.0

EOSS_MMRM = Estimand-Oriented Sample Size and Power Simulation using MMRM (Mixed-effect Model for Repeated Measures).

This app helps estimate how many patients may be needed in a repeated-measures clinical trial, especially when some patients stop treatment early.

Users can change the treatment effect, dropout rates, follow-up assumptions, and sample size, then see how those choices affect the chance of detecting the treatment effect.

This HTML/JavaScript version runs in a browser without R, Shiny, Python, or a server. The original R/mmrm application remains the reference for statistical validation.

Based on: Dai J, Hoxhaj V, Gardener L, Checketts D, Kong X. EOSS_MMRM V1.0: A Shiny Application for Estimand Oriented Sample Size and Power Simulation using MMRM Modeling. PHUSE US Connect 2024 — PAP_AS03 ↗  |  PRE_AS03 ↗  |  GitHub ↗

Method: Implements an iterative GLS approximation with EM-type covariance updates for MMRM-style contrasts. Use 2000+ simulations for stable Monte Carlo power curves; this browser tool is not claimed to reproduce published Figure 4 percentages within a fixed numerical tolerance.

Three concepts you need to understand

MMRM (Mixed-effect Model for Repeated Measures) is a statistical method designed for clinical trials that measure patients at multiple time points — for example at Week 6 and Week 12. Instead of looking at only the final measurement, MMRM uses all observations together, accounting for the fact that measurements from the same patient are correlated. This makes it more efficient and better at handling missing data than simpler methods.

Estimand is a formal term from the ICH E9(R1) guideline (2019) meaning "what exactly are you trying to measure?" Before running a trial, you need to decide: if a patient drops out, what does their missing data represent? Different answers lead to different estimand strategies — and different power calculations.

Key insight: Different dropout strategies give different power. Ex2 (hypothetical, no follow-up) gives the highest power because all missing data is handled by MMRM assuming MAR. Ex1 (treatment policy, partial follow-up) is slightly lower. Ex3 (placebo-like imputation) is the most conservative.
📋

Ex1 — Treatment Policy

Include all patients regardless of dropout. Patients who stop treatment are followed up and their measurements are used. Estimates real-world effectiveness. Some dilution of effect because dropouts may have lower efficacy.

🔬

Ex2 — Hypothetical Strategy

Ask: what would have happened if everyone completed treatment? Dropouts are not followed up. Missing data is handled by MMRM assuming Missing at Random (MAR). No dilution — highest power of the three.

🔌

Ex3 — Placebo-like Imputation

Sensitivity analysis: assume dropouts returned to placebo-level response (zero treatment benefit). Most pessimistic scenario — lowest power. Used to stress-test how robust results are if the drug stops working after dropout.

What each parameter means

Sample Size (SS)

Total number of patients randomised across both arms. The X-axis in the power curve chart.

Efficacy at each visit

The expected difference between treatment and placebo for patients who complete all visits. E.g. 4-point difference at Week 6, 6-point at Week 12.

ET Rate (Early Termination)

Proportion of patients who drop out before each visit. Set separately for treatment arm (usually higher) and placebo arm. Incremental — e.g. 20% drop out before Visit 1, and another 20% between Visit 1 and Visit 2.

EFU Rate (Efficacy Follow-Up)

Of the patients who dropped out, what fraction comes back for a follow-up measurement? 0 = Ex2 strategy (nobody followed). 0.5 = Ex1 strategy (half return). Higher values dilute the overall treatment effect.

EFU Efficacy

For patients who did return for follow-up: how much treatment effect remains? E.g. 2 out of the original 4-point effect. Set to 0 for Ex3 (placebo-like imputation).

Correlation between visits

How strongly are a patient's Visit 1 and Visit 2 measurements correlated? Higher correlation means Visit 1 data helps predict Visit 2, increasing efficiency. Typical range 0.3–0.7.

Why Ex2 > Ex1 > Ex3 always

The hypothetical strategy (Ex2) never dilutes the treatment signal — MMRM uses MAR to handle all missing data. Treatment policy (Ex1) includes some follow-up data from dropouts at reduced efficacy, slightly lowering the average effect size. Placebo-like imputation (Ex3) actively sets dropout patients to zero effect, giving the most conservative estimate. This ordering holds across all sample sizes and is the key result of Figure 4 in the paper.
